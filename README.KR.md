<h1 align="center">느티나무 교실 도우미</h1>

<p align="center">
  중학교 특수학급을 위한 웹 앱입니다.<br />
  되풀이되는 서류 일은 앱이 하고, 선생님은 학생에게 더 많은 시간을 쓸 수 있게 합니다.

# 해결하려는 문제

특수교사와 실무사 선생님은 매주 같은 모양의 서류 일에 많은 시간을 씁니다.

* 여러 학급 시간표를 보며 **학생별 시간표**를 손으로 다시 만들기
* **개별화교육계획**을 학교 한글(HWP) 양식에 옮겨 적고, 깨진 모양을 다시 맞추기
* 약속판 · 칭찬통장 · 이름표 · 학습지 같은 **교실 자료**를 하나씩 그리기
* **활동일지**는 종이에 적고, 인수인계는 말로만 전하기

**느티나무 교실 도우미는 이 일들을 한곳에 모았습니다.** 정보를 한 번만 입력하면 바로 인쇄할 수 있는 문서가 만들어집니다.

| 💰 **칭찬통장 만들기** | 보상용 통장을 손으로 만듦 | 표지 · 속지 · 거래 내역이 있는 통장, A4 한 장에 4쪽씩 인쇄 |

| ✍️ **긍정 · 감성 필사 교실** | 필사 학습지를 직접 준비함 | 어휘 · 문장 · 이야기 단계별 칸 공책 학습지 (따라 쓰기 / 보고 쓰기 / 빈칸, PDF) |
| 👥 **학생 정보 관리하기** 🔒 | 도구마다 같은 학생 명단을 다시 입력함 | 모든 도구가 함께 쓰는 학생 명단 하나 |

# 사용 방법

1. 앱을 열고 메인 화면에서 도구 카드를 고릅니다
2. 정보를 입력합니다 (또는 학생 명단에서 학생을 고릅니다)
3. 미리보기를 확인하고 **다운로드 / 인쇄**합니다

> **행정 업무** 탭과 학생 정보 관리는 로그인해야 쓸 수 있습니다.

# 작동 원리

### 🗓️ 시간표: 브라우저 안에서 처리
학급 시간표 엑셀 파일을 **브라우저 안에서** 읽습니다. 학생마다 교시별로 어디에 있는지 계산해 학교 워드 양식을 채웁니다. 파일은 서버로 보내지 않습니다.

### 🎨 교실 자료: 코드로 SVG 그림을 그림
약속판 · 칭찬통장 · 이름표 · 학습지는 코드가 SVG 로 직접 그립니다. 이름과 날짜가 늘 정확하고, 미리보기 그림이 그대로 인쇄 · 저장됩니다.

### 📝 개별화교육계획: 문서 하나, 보기 두 가지
```
학교 빈 양식(.hwp) ──▶ 학생 · 영역마다 조립 ──┬──▶ 웹 편집기 (화면)
                                             └──▶ 내려받기 (.hwp)
```
* 서버가 학교 한글 빈 양식의 문단과 표를 학생마다 · 교과마다 복사하고 칸에 글을 넣습니다.
* **같은 조립 결과**로 편집 화면도 그리고 한글 파일도 만듭니다. 그래서 글 · 표 · 글자 모양 · 칸 높이 · 쪽 나눔이 서로 같습니다.
* 고친 내용은 칸마다 저장됩니다. 두 선생님이 같은 칸을 동시에 고쳐도 두 사람의 내용이 함께 합쳐집니다.

### 🔐 개인정보 보호
* 로그인 아이디 · 비밀번호는 서버 환경 변수에만 해시로 둡니다.
* 학생 실명은 외부 AI 에 보내지 않고, 개별화교육계획에는 AI 기능을 쓰지 않습니다.

# 시작하기

**Node.js 26 이상**이 필요합니다 (`.nvmrc` 참고).

```bash
npm install
npm run dev        # http://localhost:3000
```

배포용: `npm run build && npm start`

### 로그인 설정
```bash
node scripts/hash-password.mjs <아이디> <비밀번호>
```
나온 값(`ADMIN_ID`, `ADMIN_PASSWORD_SALT`, `ADMIN_PASSWORD_HASH`, `AUTH_SECRET`)을 이 컴퓨터에서는 `.env.local` 에, 배포할 때는 배포 서비스(예: Vercel)의 환경 변수에 넣습니다.

### 데이터 저장
`KV_REST_API_URL` / `KV_REST_API_TOKEN` (Upstash Redis) 이 있으면 거기에, 없으면 `data/` 폴더의 JSON 파일에 저장합니다.
